## 要解决的问题

1. 现在收件箱里看不出「是谁发给我的」。每张卡片要用一句话写出**让工单进我收件箱的那一方 + 做了什么**。
2. 标题有时很长：列表里**完整显示标题，折行，不加省略号、不截断**。
3. 每张卡片显示**最后一条回复的时间**（相对时间如「3 小时前」，`title` 属性悬停显示完整时间如 2026-11-03 14:20）；没有任何回复的显示「创建于 …」。
4. 不再单独显示「我是指派人 / 我是发起人」身份标签，身份由那句话体现。
5. 次要信息里固定显示「发起人 某某」，以及编号、类型（任务/反馈）、标签 chip。
6. 未读工单标题前有小圆点、标题加粗。

## 两种视图（页面顶部切换：「按时间 / 按人」，默认按时间，切换要能真的点通，纯前端 JS）

- **按时间**：只列轮到我的工单（收件箱），按最后回复时间倒序。顶部显示「收件箱 9」数量。
- **按人（按往来对象分组）**：
  - 往来对象 = 我是指派人时是发起人，我是发起人时是指派人；访客填的反馈工单归访客（名字后标「（访客）」）；
    自己派给自己的归「我自己」；尚未指派、等我初筛的单独一组「待初筛」（组内每张写发起人）。
  - 每组组头：对方名字（头像圆圈用姓的首字）+「轮到我 2 · 等他 3」计数。组按组内最近一次回复倒序。
  - 组内上半「轮到我」的卡片（正常样式）；下半「在等他」的卡片默认**折叠**，点「在等他 3 张 ▸」展开，
    展开后卡片样式明显弱化（灰一点），一句话写成「等 李四 处理 · 2 天前」之类。
  - 收件箱数量只算「轮到我」，「在等他」不计数。

## 一句话写法（示例，照这个风格）

- 新指派：「张三 派给你」；改派：「李四 改派给你」
- 对方提问：「张三 回复了，问你一个问题」
- 已交付待验收：「李四 交付了，等你验收」
- 退回修改：「张三 退回了，要你修改」
- 访客回复了：「访客 王五 回复了」；访客补全了说明：「访客 王五 补全了说明」；访客未补全：「访客 王五 还没填说明」
- 你的 Agent 回复了：「你的 Agent 回复了」
- 待初筛：「赵六 新建，等你初筛」

## 技术约束

- 单个自包含 HTML 文件：内联 CSS 与 JS，**不引用任何外部资源**（无 CDN、无外链字体、无图片文件）。
- 系统字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 不要做设备外框、不要 `?variant=` 切换。
- 卡片点击无需跳转（`href="#"` 即可）。
