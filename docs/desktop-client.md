# Orca 插件

常驻提醒由 Orca 插件承担（ADR 0020）：它在成员的 Orca 里订阅通知流、弹出桌面通知、
显示未读并标为已读；要处理工单时，在浏览器里打开。插件在本仓库之外开发和发布，
安装入口见 [Orca 插件仓库](https://github.com/allanpk716/taskboard-orca-plugin)。

## 连接平台

签发流程沿用原来的网页确认 + 本机回环 + PKCE（ADR 0004），安全习惯不变：

1. 在插件里发起连接，插件在本机回环端口监听，并打开浏览器进入平台的
   「连接这台电脑」确认页；
2. 成员确认「连接」后，平台把一次性 code 回传给插件的回环地址；
3. 插件用 code 和 PKCE verifier 换取客户端凭证（前缀 `tbc_`），之后凭它调用
   通知接口。

连接约定：

- `hostname` 传「Orca · <主机名>」，「我的 → 已连接设备」照此显示，并可单独撤销；
- 请求带 `User-Agent: taskboard-orca-plugin/<语义化版本>`，平台据此在设备列表
  显示插件版本；
- 客户端凭证的权限边界见 [`docs/api.md`](api.md) 的 `client_scope` 说明。

旧 Windows 桌面客户端已下线，不再提供下载和更新；已签发的客户端凭证不被吊销，
成员换装插件前，旧客户端的通知照常可用。
