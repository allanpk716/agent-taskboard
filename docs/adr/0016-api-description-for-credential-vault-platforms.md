# ADR 0016：为代管凭证的 Agent 平台开放接口描述

## 状态

已接受（2026-11-02 讨论定稿）。

## 背景

ADR 0007 让成员 Agent 用环境变量 `TASKBOARD_TOKEN` 长期保存 token，这个做法适合能读说明书、能开终端的 Agent（CC、Codex 等）。Rakazo 这类自建 bot 平台不一样：token 放进提示词，模型能直接看到；放进运行环境变量，bot 有终端能力，模型照样能读出来。这两种做法都违反平台"token 不让模型看到"的规矩。这类平台自带凭证保险箱，导入 OpenAPI 描述或接入 remote MCP 时，token 加密存储，调用时由平台注入，模型始终看不到。对它们来说，这是唯一干净的凭证通道。

## 决策

在 `GET /openapi.yaml` 公开一份静态的 OpenAPI 接口描述，文件放在仓库的 `docs/openapi.yaml`，紧挨着 `docs/api.md`。两者是同一份契约的两种写法，端点变更时要一起改。`servers` 按请求 host 生成，做法与 `agent.md` 的 `{{BASE}}` 相同。`info.version` 固定为 `v1`，与 `/api/v1` 对齐，只有破坏性变更才改。这个文件免凭证公开，和说明书同等对待。

不做 MCP 端点。只有当接口描述确实不够用、出现非做不可的场景时再讨论。如果将来要做，方向是在 Go 主程序内实现，认证直接透传 Bearer，MCP 自身不建用户体系。

使用这条通道的 Agent 仍然是**成员 Agent**，没有新身份，也没有新权限。说明书的凭证约定里增加一条分支：已经接好平台工具的 Agent 不去找 `TASKBOARD_TOKEN`，直接调用工具，只有工具返回 401 时才停下来找主人。工单指令和交接文案不改。成员从接入文案中取出 token，自己贴进平台的保险箱，签发界面暂时不改。

附件通过**附件链接**交给成员 Agent：接口描述里不放直接下载附件的操作，改为 `get_attachment_link`，返回一个短时效、只对应单个附件、只读的下载地址（附带过期时间、MIME、大小、文件名）。原因是凭证保险箱类平台把工具响应一律当文本读，截图字节到不了模型；拿到地址后，Agent 用自己的下载能力（终端 `curl` 等）取文件，能看图的 Agent 就能看截图。地址本身就是凭证，所以权限收到最小：签名不在服务端存状态（HMAC），其中包含签发它的成员 Agent 和附件，10 分钟过期；每次下载都重新核对该 Agent 的 token 未吊销、工单仍在、它仍有权读这张单，任何一项不满足即失效。这与 #33 取消访客签名地址并不冲突：访客那边是长期地址，泄露后风险持续；这里的地址只活 10 分钟，并且绑定一个随时可吊销的 Agent。

平台专属的执行流程不进本平台的文档。说明书和接口描述面向所有外部 Agent，只写平台本身的规矩：成员 Agent 追问访客先写草稿；信息完整的单不随手回复（成员 Agent 回复算主人一方行动，会把等待方切成访客）；附件先取链接再下载，链接不外传。至于定时初筛多久跑一次、"已处理"的状态记在哪里、超过几天提醒，属于使用方（例如 Rakazo 的 routine 提示词）自己的事，不写进本仓库。

红线：访客链接管理（含建单时内嵌生成访客链接）、成员管理、管理员操作和通知流，永远不放进接口描述。由一个测试来守住：接口描述中的每个操作都必须在路由中真实存在，并且不能出现红线路径。

## Considered Options

- **应用目录（Composio、Pipedream 托管连接器）**：数据要经过第三方云，与私网部署的理念冲突。
- **Python 边车 MCP**：部署面翻倍；要做 MCP 也应在进程内。
- **一开始就做进程内 MCP**：接口描述已能让平台安全接入，MCP 的高层工具要等实际使用暴露出问题后才知道该封装什么。
- **要求凭证才能读取接口描述**：描述里没有秘密，`api.md` 本身已经公开了全部端点；而且平台导入描述时不一定会带凭证。

## Consequences

- 红线只靠"描述里不写"：`tbag_` token 本身有成员的全部权限，服务端不会额外拦截描述以外的接口。之所以可以接受，是因为模型拿不到 token，只能调用平台从描述导入的操作。如果将来需要由服务端强制执行红线，这会是做 MCP 的理由之一。
- 公开端点没有按 IP 限流，限流不在本决策范围内，需要时在反向代理层另做。
- MCP 解决不了截图问题，至少在 Rakazo 上如此：它把 MCP 工具结果（包括 `image`、`resource` 类型）整体序列化成文本，图片同样到不了模型。所以"要看截图"不构成做 MCP 的理由，附件链接已经覆盖了这个需求。
- 接口描述需要随 `api.md` 同步维护，路由一致性测试只能拦住路径和方法的漂移，拦不住字段形状的漂移。
